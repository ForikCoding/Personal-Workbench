# dsh-workbench 2.4.13 — 跳转只跳模板，折叠照旧

2.4.12 加了两样东西：一个跳转列表，一个折叠视图。跳转列表列的是**整份模板的全部结构**（`<head>`、`<style>`、`<body>`、每个 `<div>`…），答的不是被问到的问题。这一版把跳转收回到**一个去处**。

## 1. 跳转：只剩一个按钮

模板那一行右边现在是一个按钮：

```
模板                                  跳转到模板  折叠视图  添加动作
```

点它 → 编辑框跳到 `<!-- template-begin -->` 那一行并选中整行。就是这一处。

- 没有区间标记（模板里缺 `template-begin` / `template-end`）时，按钮不出现——没有可跳的地方，就不给一个点了没反应的控件。
- 结构本身不再需要「跳」：那正是折叠视图在做的。在一份三百行的模板里，需要快速到达的只有一处，其余是读。

## 2. 折叠视图：没变

同一行的「折叠视图」照旧，每个块的开头有 `▾`：

```
  7  ▸   <style>                      … 218 行
226   </head>
227  ▾<body>
228    ▾<div class="task-board">
```

- `… 218 行` 是这次折叠藏起来的行数。
- 块从标签结构读出来：`<style>`/`<script>` 整块跳过，注释里的标签不算，没闭合的标签只结束在自己那一行。
- 折叠视图只读；点任意一行回到编辑、跳到那一行并选中。
