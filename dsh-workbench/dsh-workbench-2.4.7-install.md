# dsh-workbench 2.4.7 版 安装说明（结果页重排）

```
dsh-workbench-2.4.7.tgz
```

**客户端（client.js）改了 → 必须重启 DSH Desktop，再刷新页面。**

---

## 先说诊断

结果页从截图看有八处问题，分两类：**重复**和**没有层次**。

### 重复（同一个页面出现两次的东西）

1. **两个长得完全一样的输入条**。上面「这次要做什么? + 运行」，下面「说明要改哪里… + 重新生成」：
   同一个聊天式输入框、同一个黑色药丸按钮、都没有一句话说自己干什么。用户不知道该往哪
   个框里打字。它们**功能不同**（一个是新跑一次，一个是在当前结果上改），但界面把它们
   做成了同一个东西。
2. **两个重量相同的主动作**。`运行` 和 `重新生成` 都是黑色药丸，一个是页面主动作，一个
   是次要动作，视觉上却在抢同一个点击。
3. **`编辑` 在右上、`重新生成` 在页底**，两个都是"改这份结果"，被一整篇文档隔开。

### 没有层次

4. **`已完成 ⌄` 是裸的一行**，直接贴在正文下面 —— 它其实是"这份结果是怎么来的"的记录，
   却长得像正文的下一节。而且行里只有结果词，没有说明展开后有什么。
5. **`运行时权限：工作区内修改`** 是一行孤零零的灰字，没有任何归属。
6. **页头不吸顶**。文档一长，`返回`/标题/运行全部滚走（第一张截图里 `返回` 就是被裁掉一半的）。
7. **16px 等间距**用在"页头-输入-文档-改这一版-轨迹-脚注"五段上，文档和上面的输入框之间
   没有区别，看起来像一段贴一段。
8. 文档容器是 12px 内边距 + 1px 边框，模板自己又画一层卡片，双层框（这条只能减轻，模板
   是用户自己写的 HTML，不能改）。

## 改了什么

### 1. 「改这一版」——把第二个输入框变成一个有名字的块

```
┌ 改这一版 ──────────────────────────────────────┐
│ [ 说明要改哪里，例如「按时间倒序」   ] [重新生成] │
│ 修改记录 · 1 次                     回到上一版 │
│ 重点看影响分析那一段        09:12              │
│ 修改记录与上一版只保留在本次会话里…            │
└────────────────────────────────────────────────┘
```

- 淡底色 + 描边 + 标题，是一个**块**，不再是一条漂浮的输入框；
- 里面的输入框改成 13px 的扁平描边字段（原来复制聊天输入框：14px、白底、软阴影）；
- `重新生成` 从黑色药丸改成**描边按钮** —— 全页只剩下一个主动作（`运行`）；
- 这样两个输入框一眼可分：上面是"跑一次"（浮起的白底 + 黑药丸），下面是"改这一版"
  （淡底块 + 描边按钮）。

### 2. 页头吸顶

`PageHead` 加 `position: sticky; top: 0`，配不透明底色和一条下分割线：文档再长，`返回`、
卡名、`编辑`、`运行` 一直在手边。三个整屏页（运行记录 / 结果 / 配置）共用这个页头。

### 3. 轨迹变成一块记录

```
┌──────────────────────────────────────────────┐
│ 已完成 · 3 步                            ⌄   │
│ 思考 · 先读任务单，再找改动点。               │
└──────────────────────────────────────────────┘
```

- 淡底 + 描边 + 圆角，成为独立的块，不再是正文的下一节；
- 表头右侧加了**步数**（`· 3 步`）：原来只有「已完成」，没有任何理由去展开它；
- 表头 12px、次要色、hover 转主色；展开箭头移到整行右端（全宽折叠行的常规位置）；
- 计数按**去掉内部 schema 调用后**的行数算，和点开看到的行数一致。

### 4. 权限脚注

`运行时权限` 加了上分割线和 10px 内距，读作页面脚注，而不是轨迹块的最后一行。

### 5. 节奏

五段间距 16 → 18px，页头固定后内容滚动的层次才成立。

## 安装

```powershell
$profile = "$env:DSH_HOME\profiles\$env:DSH_PROFILE"
$target  = Join-Path $profile 'node_modules\dsh-workbench'
$tmp = Join-Path $env:TEMP ('wb-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $tmp -Force | Out-Null
tar -xzf .\dsh-workbench-2.4.7.tgz -C $tmp
Copy-Item (Join-Path $tmp 'package\*') $target -Recurse -Force
Remove-Item $tmp -Recurse -Force
```

**重启 DSH Desktop**，再 `Ctrl+F5`。

## 没做的事（需要你定）

`运行` 和 `重新生成` 对 `instructionMode = none` 的卡（比如「我的任务」）**功能上确实重叠**：
两条路都是"再跑一次"。要真正去掉一个，得决定按哪个语义合并 —— 这属于改行为，我先没动。
