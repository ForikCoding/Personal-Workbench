# dsh-workbench 2.4.16 — 结果页那个操作区，从「两块灰板」改成「一条记录 + 一个 dock」

## 丑在哪

你圈的那一块其实是**两个盒子**，而且穿得一模一样：

```
┌ 灰底 2% + 细边 + 10px 圆角 ────────────────────┐
│ [在上一版上改|从头跑|编辑]                       │   ← 操作区
│ ┌ 又是白底 + 又是一圈细边 ───────────┐ [重新生成] │
│ │ 说明要改哪里，例如「按时间倒序」    │           │   ← 框里套框
│ └───────────────────────────────────┘           │
└─────────────────────────────────────────────────┘
┌ 灰底 2% + 细边 + 10px 圆角 ────────────────────┐
│ 已完成 · 19 步                                                            ⌄ │
└─────────────────────────────────────────────────┘
```

四个问题：

1. **两块同重量的灰板叠在一起**，读起来像「一张带条纹的表单」，而不是「这里写」和「这是怎么来的」两件事。
2. **框里套框**：一个白色输入框套在灰色板子里，为了一行字画了两圈边；占位符的左边缘还比上面那排选择器往里缩了 11px，两个左边界对不齐。
3. **箭头在 1400px 外**：`已完成 · 19 步` 是一整行，折展箭头被推到最右，跟它的字完全脱节，所以那行看起来像一条空带子。
4. 占位符用的是最淡的 caption 灰，加上一个禁用的空壳按钮，整块第一眼像**被禁用**。

## 改成什么

- **操作区变成 dock**：白底、细边、一条很轻的投影，再加 12px 圆角。页面里从此只有一个「被抬起来」的面——因为它是唯一**往里写字**的地方；上面的文档是产出，下面的记录是历史。
- **输入框不再自己带框**：透明、无边框，字直接落在 dock 的内边距上，左边界和上面那排选择器的第一个字对齐。
- **焦点环画在 dock 上**（`focus-within`），不是画在文本框上——没有框的输入框去描边，只会把第二个框又画回来。
- **占位符从 caption 灰抬到 tertiary 灰**：还在，但不再像禁用。
- **`已完成 · 19 步` 变成一枚小 chip**：前面加一个状态点（正常是灰点，失败/中止变成警示色），箭头紧跟字数后面，hover 时整枚有淡底。它不再是板子，而是操作区下面的一行历史。
- **运行字段同样去框**：「从头跑」那套字段和「在上一版上改」那套现在是同一个形状——一块面，一个字段。
- 顺便把选择器收紧（`padding 1px/gap 1px`、行高 17px），整块高度从约 90px 降到约 78px。

交互不变：Enter 提交、Shift+Enter 换行、输入法候选打字时不误提交、空输入时按钮禁用——这些都保留。
