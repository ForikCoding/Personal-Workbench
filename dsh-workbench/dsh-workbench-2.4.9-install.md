# dsh-workbench 2.4.9 — 配置页

上一版把结果页的动作收成一个块；这一版动的是它的邻居：**卡片配置页**。

## 诊断

截图上的配置页有六个问题，按严重程度排：

| # | 现象 | 为什么是问题 |
| --- | --- | --- |
| 1 | 页面顶着「工作台 / 把 Git、Agent 与测试状态收在一页」，下面只有一行孤零零的 `‹ 返回` | 那是**工作台首页**的标题。配置页自己没有标题，于是借了首页的；滚下去以后你完全不知道自己在配哪张卡 |
| 2 | 工作目录占两行（leaf + 路径），邻居「模型」一行 | 一行高一行矮，两行网格**对不齐**，而网格存在的全部意义就是对齐 |
| 3 | `区间 255–259 · 动作声明 0 条 · 14,772 / 32,768 字节 · 添加动作` 一行灰字里混着四种东西 | 「添加动作」是下划线，看起来像这句话的第四项，实际是这行唯一能按的东西 |
| 4 | 预览的「骨架预览，区间尚未填充」塞在灰框里 | 它是这块内容的说明，却压在被说明的内容上；框里还有一个和文档同色的白板 |
| 5 | 底栏 `保存 关闭` 跟页面同一种白，只有一条细线 | 滚动时它盖住编辑器和预览的下沿，看起来像**内容被切掉了**，不像一条栏 |
| 6 | 所有控件 28px / 12px，卡片名和「必须」下拉一样重 | 表单感缺失；名字是这页的主语，长得跟一个下拉框一样 |

## 六处改动

1. **配置页有自己的头**：`返回` 在上，标题是卡片名，下面一行小字写「配置 · skill · 权限模式」。标题读的就是「卡片名称」那个字段存下来的值，所以它不会和字段打架 —— 之前是把名字和 skill 抄到头上当死文本，那份抄本没法编辑，才被拿掉的；这次头是**标签**，不是第二个编辑器。
2. **控件统一到 32px / 13px**，边框用亮一档的 `border-l2`：表单看上去像表单，名字字段和下拉框一样高，但字大一号。
3. **工作目录压成一行**：叶子名靠左，完整路径靠右、超长省略、鼠标悬停看全。四行两列从此**同一基线**，`选择目录` 仍在值外面。
4. **模板的动作搬到组标题那一行**：`插入标记` / `添加动作` 变成两个描边按钮，占位在右端；下面那行只留事实（区间 · 动作条数 · 字节 · 未保存）。原来那三个下划线按钮从这行移除。
5. **预览有框有底**：说明文字升到组标题右端，和 `模板` 的按钮同一条右边缘；灰框换成淡底容器 + 白色虚线井，最小高度跟编辑器齐平，两栏一起收尾。
6. **底栏像条栏**：加了一层向上的极淡投影（白底 + 白页，只有一条线时真的像切断），并挨着 `保存` 写了「有未保存的改动」—— 原来这句只在编辑器上方那行，那行可能已经被滚过去了。

顺手修的：`基本信息` 与下半页之间补了与页头同款的细线（文档和事实是两种东西）；两栏时的 `.section + .section` 细线只画在右栏、并把「预览」标题压低 1px，已去掉；页签条从 `bg-layer-2` 换成 5% 淡底（这个主题里两个 layer 都是纯白，条其实是不存在的）。

## 验收

1. 打开任意卡片的 `配置`：顶部是 `‹ 返回` + 卡片名 + `配置 · <skill> · <权限>`，不再是「工作台」。
2. 改「卡片名称」→ 失焦 → 标题跟着变。
3. 工作目录那一格：名字和路径**同一行**，和左边「模型」一样高。
4. 模板：`插入标记 / 添加动作` 在标题右端；下面灰字只有事实，没有下划线。
5. 编辑器里改一个字 → 底栏出现「有未保存的改动」，并且向下滚动时底栏盖住内容的地方有一层淡淡的影。
6. 预览那栏底部和编辑器底部齐平；说明文字在「预览」右边。

## 没做的事

- 没给编辑器加语法高亮：模板是 HTML + 自己的 `<!-- template-begin -->` 标记，高亮要引入一个词法器，和这轮「只看排版」的诉求不成比例。
- 没动「保存」的位置：它仍然只在底栏。放在页头会被当成"随手点一下"，而这页保存的是模板全文。
- 窗口窄于 1100px 时仍是「模板 / 预览」两个页签，这次只把页签条的底色补上了。
