# dsh-workbench 2.4.8 版 安装说明（运行 / 重新生成 / 编辑 合成一处）

```
dsh-workbench-2.4.8.tgz
```

**客户端（client.js）改了 → 必须重启 DSH Desktop，再刷新页面。**

---

## 先说诊断

你问的是「运行和重新生成是否可以合并」。答案：**可以合，但不能合成一个按钮** ——
它俩的差别不是长相，是**交给模型的底稿不同**：

| | 运行 | 重新生成 |
| --- | --- | --- |
| 交给模型 | skill + 模板（+ 说明） | **当前这一份 HTML** + 一句话 |
| 结果 | 从头重跑一份 | 在旧稿上改 |
| 回退 | 无 | 有「回到上一版」，且记进修改记录 |

如果简单合成一个按钮、永远带着上一版当底稿，那"重跑"就不再重读工作区 —— 模型会照着
旧报告改写，看着成功、内容其实是上一版的翻版。`任务分析` 这种长报告尤其糟。

所以合的是**控制**，不是语义：全页只留**一个输入区、一个动作按钮**，把"底稿"变成界面上
可见的一个选择。顺带把 `编辑` 也搬进来 —— 它本来就是第三种"改这份结果"的方式，却独自
挂在页头，和另外两个被一整篇文档隔开。

## 改了什么

### 1. 结果页只剩一个动作块

```
┌──────────────────────────────────────────────────────────┐
│ [在上一版上改] [从头跑] [编辑]                            │
│ [ 说明要改哪里，例如「按时间倒序」        ] [重新生成]     │
│ 修改记录 · 1 次                              回到上一版    │
│ 把标题改成一句话总结                14:31                 │
│ 修改记录与上一版只保留在本次会话里…                        │
└──────────────────────────────────────────────────────────┘
```

- 三选一是**分段控件**：选中的那格是白底小片，其余是文字；三格分别是三种改法；
- 选「从头跑」→ 下面的输入框和按钮**换成运行的那一套**（按钮变黑药丸 `运行`，需要说明的
  卡里字段占位是「这次要做什么？」）；
- 选「编辑」→ 文档原地变成 HTML 编辑器（和之前一样，块的 `保存/取消` 结束这个模式）；
- 三种里只有一种能同时出现在屏幕上，所以页面上永远只有一个输入框、一个按钮。

### 2. 页头不再有 `运行` / `编辑`

页头只剩 `返回` + 卡名 + skill 标签。原来它承担两件事，现在都归块：卡上的 `运行` 药丸和
块里的 `从头跑` 打的是同一个接口、同样的参数，本来就是同一个动作的两个入口。

### 3. 块放在文档末尾（原来顶部那条不再存在）

顶部那条运行条从结果页移除。理由是它是"对这份结果做什么"的动作，贴着它所改的文档才读得
通；块也正好落在你读完文档的位置。**运行记录页不变**：那里顶部的运行条仍在，`运行` 还是
页面主动作 —— 重跑这件事本来就该在运行记录页做一次点击。

### 4. 不需要说明的卡（instructionMode = none）

`从头跑` 没有字段可写，块里就一句说明 + 一个按钮：

```
│ 这张卡不需要说明，直接按当前工作区重新跑一遍。        [运行] │
```

一句 `这张卡不需要说明…` 是必要的：不然空块看起来像加载失败，而不是"这张卡本来就不用写"。

### 5. 运行中

跑起来时选择器让位给 `取消`（同一次运行里换模式没有意义，而且会和这次运行抢卡片）。
`取消` 就在块里，也就是你刚按下去的位置。

### 6. 不可运行的原因挪到块下面

`模型不可用` / `工作区没选` / `工作区目录不在` / `这个阵容没有运行入口` 这四条，原来在
顶部运行条下面，现在贴在块的下沿 —— 解释的是它上面那个被禁用的按钮，不该隔着一整篇文档。

## 安装

```powershell
$profile = "$env:DSH_HOME\profiles\$env:DSH_PROFILE"
$target  = Join-Path $profile 'node_modules\dsh-workbench'
$tmp = Join-Path $env:TEMP ('wb-' + [guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $tmp -Force | Out-Null
tar -xzf .\dsh-workbench-2.4.8.tgz -C $tmp
Copy-Item (Join-Path $tmp 'package\*') $target -Recurse -Force
Remove-Item $tmp -Recurse -Force
```

**重启 DSH Desktop**，再 `Ctrl+F5`。

## 验证

1. 打开有结果的卡（比如「任务分析」）：页头只有 `返回` / 卡名 / skill 标签，右边**没有按钮**。
2. 滚到文档末尾：一块淡底方框，第一行三格 `[在上一版上改] [从头跑] [编辑]`，默认选中间
   左边的第一格；下面一个细描边输入框 + 描边按钮 `重新生成`。
3. 点 `从头跑`：输入框和按钮换成运行的那套（按钮变黑 `运行`）；点回 `在上一版上改` 换回来。
4. 点 `编辑`：文档变成 HTML 编辑器，块消失；`取消` 后回到文档，块回来。
5. 跑一次：选择器消失，块里只剩 `取消`。
6. 「我的任务」这种不需要说明的卡：`从头跑` 里没有输入框，只有一句说明 + `运行`。

## 没做的事

- 块不会吸底。文档特别长时，要改结果得滚到末尾 —— 运行记录页那条运行条仍在顶部，重跑不必
  滚到底。
- `编辑` 只在有结果时出现；没跑过的卡块里只有 `从头跑` 一格（选择器不显示，避免只有一格的
  假选择）。
