# dsh-workbench 2.4.12 — 模板不再是一条三百行的长带子

模板编辑框里加了两样东西：一个**跳转列表**，一个**折叠视图**。它们读同一份文本，都是为了让「找到某一段」不必靠滚。

## 1. 跳转…

模板那一行的右上角，「添加动作」旁边多了一个下拉。里面是这份模板的**结构**，不是它的每一行：

```
跳转…
  填写区间 · 第 30 行
  <html lang="en"> · 1
    <head> · 3
  <style> · 7
  <body> · 227
    <div class="task-board"> · 228
      <div class="table-wrapper"> · 229
  <script> · 300
```

选一个，编辑框跳到那一行、把这一行选中（不是只滚动：选中是「就是这里」的确认）。区间那一项优先——那是模板里唯一由 agent 填写的地方。

列表从文本现算，所以它跟着你的编辑走；只有**跨行**的块才会出现，一行写完的 `<tr>` 不会把列表撑成一张表。

## 2. 折叠视图

同一行还有一个「折叠视图 / 编辑」的开关。折叠视图里，每个块的开头行多一个 `▾`，点一下把它收起来：

```
  7  ▸   <style>                      … 218 行
226   </head>
227  ▾<body>
228    ▾<div class="task-board">
229      ▾<div class="table-wrapper">
```

- `… 218 行` 是这次折叠藏起来的行数：一个吞掉整个样式表的折叠，和一个只藏了三行的折叠，看起来不该一样。
- 折叠是**按块**的，块从标签结构里读：`<style>`、`<script>` 整块跳过（CSS 里的 `div > span` 和 JS 里的 `a < b` 都不是标签），注释里的标签也不算；没闭合的标签只结束在它自己那一行，不会把后面的内容一起吞掉。
- 折叠视图是**只读**的。它是「读」这一面，编辑永远是旁边那个输入框。点任意一行 → 回到编辑、跳到那一行并选中。

## 验收

1. 配置页「模板」那一行右边有「跳转…」下拉和「折叠视图」按钮。
2. 展开下拉，看到的是 `<head>` / `<style>` / `<body>` / `<div class="…">` 这样的块；选一个，编辑框跳到那一行并且整行被选中。
3. 点「折叠视图」：编辑框换成带 `▾` 的行列表；点 `<style>` 那一行的 `▾`，它下面两百多行变成一行 `… N 行`；再点 `▸` 展开。
4. 在折叠视图里点任意一行：回到编辑视图，光标落在那一行、整行选中。
