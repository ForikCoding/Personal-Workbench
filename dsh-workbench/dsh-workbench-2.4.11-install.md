# dsh-workbench 2.4.11 — 标题行、状态栏、以及少两行话

这一版是你指着截图说的四件事，加上编辑器对不齐的成因。

## 1. 页头那行「配置 · skill · 权限」里的方块

页头的小圆点分隔是画在每一项自己身上的伪元素。技能名那一项是**带底色的 chip**，于是那个点画在了 chip **里面**，贴着左边内边距，而 chip 又紧贴着「配置」两个字——看起来就是一个脏点和一段糊在一起的文字。

```
before                          after
配置⟨·  uf30-task-analysis⟩ · 工作区   配置   uf30-task-analysis · 工作区
   ↑ 点在 chip 里面，且左边没有间距
```

现在 chip 不再画点（方块本身就是分界），改为在它左侧留 10px。任何把 chip 放进这行的页面都一并修好。

## 2. 「区间 255–259 · 动作声明 0 条 · 14,772 / 32,768 字节」挪到尾部

原来这行在编辑器**上面**，读起来像这一节的说明文字，还白占了 28px。现在它是编辑器自己的**状态栏**：在编辑框下沿、和代码同处一个边框之内，一条细线隔开，左边三个关于文件的事实，右边「有未保存的改动」靠右。

```
┌───────────────────────────────────────┐
│ 1  <!DOCTYPE html>                    │
│ 4    <meta charset="UTF-8" />         │
├───────────────────────────────────────┤
│ 区间 255–259  动作声明 0 条  14,772 … │ … 有未保存的改动
└───────────────────────────────────────┘
```

## 3. 模板里的 HTML 没对齐 —— 是真的

两个原因，都修了：

- **字体不是等宽网格**。原来只写 `font-family: monospace`，落到系统兜底字体上，字符宽度并不一致，缩进看起来是「半个字」的漂移。现在写死了等宽栈（`ui-monospace, "Cascadia Mono", Consolas, "Courier New", monospace`），加 `tab-size: 2`，并把这条规则放进 `.editorPane .editor`（选择器更具体，应用自己的 textarea 样式盖不掉它）。
- **软换行会把行号整体推错**。textarea 默认自动换行：一行折成两行时，里面只占一个行号，从那行往下所有号码都错位。现在 `wrap="off"` + `white-space: pre`，长行横向滚动，行号永远对得上；同时 `scrollbar-gutter: stable`，长文件出现滚动条时文字不会跳一下。

## 4. 「运行时权限：工作区内修改」删了

结果页最后那行删掉，连同它的样式和文案 key。权限模式在卡片的**配置页**「基本信息 → 权限模式」里，那是它被修改的地方；每次运行页脚下重复一句不变的说明，只会让人不再看它。

## 5. 「已完成 · 19 步」默认折叠

跑完的记录默认收起来，只留一行标题（结局 + 步数 + 箭头），点开才展开步骤。运行中的记录仍然默认展开——那时候看它干活才是打开页面的理由。
