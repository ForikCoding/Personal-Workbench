# dsh-workbench 2.4.10 — 配置页的第二遍

2.4.9 把配置页重排了，但装上去以后有三处不对，都是截图里能直接看见的。

## 诊断

| 现象 | 原因 |
| --- | --- |
| 底栏那条横线**切在编辑器中间**，线下面还露着第 8 行代码和预览的横向滚动条 | sticky 的 `bottom: 0` 对齐的是滚动容器的**内容边**。面板的 `.page` 有 48px 下内边距，于是底栏被钉在高出窗口底边 48px 的位置，横线下面那一截正好是编辑器内容——看起来像栏把编辑器切了一半 |
| 预览栏比编辑器矮一截，或者反过来 | 预览的高度写死成 368px，编辑器是 340px，两个数字得手动对齐；编辑器还能被拖高，一拖就散 |
| 「骨架预览，区间尚未填充」压在**已经填满**的预览上 | 这句是无条件渲染的，只要卡有内容，它就在说反话 |

## 改了什么

**1. 底栏钉到窗口底边。** `bottom: 0` → `bottom: -48px`：把 sticky 的参考线从内容边挪到内边距外沿（也就是窗口自己的底边）。这样滚动中途，底栏下面不会再露内容；滚到头时底栏落在内容末尾，下面是干净的页面留白。

改完实测（headless，窗口 600px、内容 887px、滚到 260px）：

```
page   top=0   bottom=507
footer top=454 bottom=507   height=53
```

底栏底边 == 滚动容器底边，之前是 `507 - 48`。栏下方的编辑器内容不再可见。

**2. 预览高度跟着编辑器走。** `.panes` 从 `align-items: start` 换成 `stretch`，预览的框 `flex: 1 1 auto`，写死的 368px 删掉。现在两栏天然等高，而且编辑器被用户拖高时预览一起长。

**3. 预览的说明句分两种。** 区间是空的（`end - start <= 1`）才说「骨架预览，区间尚未填充」，否则说「按当前模板渲染」。新增 key `skillCardPreviewLive`（en: `Rendered from the current template`）。

**4. 整页压紧一点，让它在 900px 高的窗口里排得下。** 段落内边距 22→18、字段行距 18→16、编辑器 `min-height` 从 340 改成 `clamp(240px, 32vh, 380px)`——笔记本窗口里 288px，大屏长到 380px，不再用一个数对付所有窗口。

## 验收

1. 打开卡片 `配置`，**滚到中间**：底栏贴着窗口下沿，横线下面是干净的白色，不再有编辑器代码。
2. 编辑器底边和预览框底边在同一条线上。
3. 拖动编辑器右下角的把手把它拉高：预览跟着变高。
4. 「我的任务」的区间是 243–263（有内容）→ 预览右上方写「按当前模板渲染」。

## 没做的事

- 预览里的横向滚动条还在：模板正文可能比半栏宽（那张三列表就是这样），预览宁可自己滚，也不缩放到看不清字号。
- 底栏仍然在底部而不是页头：它和「删除卡片」是同一组操作，放页头会让"随手点一下"的保存和危险操作挨在一起。
